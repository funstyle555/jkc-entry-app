# 競技会申込書メーカー（試作）

JKCアジリティー競技会の出陳申込書PDFを、スマホのブラウザで自動作成する試作アプリです。

公開ページ: https://funstyle555.github.io/jkc-entry-app/

## 使い方

1. 大会を選ぶ（カードに開催日・会場・締切・競技クラスが出ます）
2. 出陳内容を入力（犬・出陳者・指導手・申込責任者）
   - **競技クラスは、1枚の申込書に複数クラスを○印できる大会なら2つまで選べます**（阿波北・徳島北・大阪北ワンズユニティ・大阪西ワンズドッグ）。もう一度押すと選択が外れ、重ねられない組み合わせを押すとそのクラスに選び直します。2クラスのときは「1度＋ビギナー1」のように確認画面・ファイル名にも出ます
   - 1枚につき1クラスまでの様式（京都トレーナーズ・近畿ブロック・東京ブロック）は、1つだけ選ぶ形（押し直しで切り替え）になります。2クラス申し込むときはクラスごとに1枚ずつ作成してください
   - 重ねて出陳できるのは「1度＋ビギナー1／ビギナー2」の組み合わせだけです（2度・3度の犬はビギナーに出陳できません／各大会の案内書）
   - 生年月日は「年・月・日」の3つのプルダウンから選びます
   - 登録済みの内容を直したら「入力内容を更新（保存）」で上書き保存できます（画面下の「更新」でも可）
   - 犬名（カタカナ）は、カタカナ欄のある様式（東京ブロック・泉大津など）で使われます
   - 大会を変えるときは、入力画面の上の「📅 大会を選びなおす」で大会選択に戻れます（いま選んでいる大会名が出ます）
   - 入力画面の上の「💾 バックアップ・保存へ ↓」を押すと、下のバックアップ欄が開いてその場に移動します
3. 「申込書PDFを作成する」でPDFを保存（ファイル名は「大会名_開催日_出陳申込書_呼び名.pdf」。2クラスのときは末尾に「_1度＋ビギナー1」が付きます）
4. 作成後の画面の「🖨️ 印刷する」から、できたPDFをそのまま印刷
   - PC・Mac: 印刷ダイアログが開きます
   - iPhone・iPad: PDFが新しいタブで開きます。印刷画面が出ないときは、共有ボタン（□↑）→「プリント」
   - Android: PDFが新しいタブで開きます。開いたPDFのメニューから「印刷」

「サンプル情報を入力」を押すと、架空のダミーデータが入ります（動作確認用）。

## 専用URL（ワンタップ読み込み）

`https://funstyle555.github.io/jkc-entry-app/#import=<Base64URL(UTF-8 JSON)>` の形のURLを開くと、
登録済みの犬・出陳者・指導手・申込責任者の内容がその端末のブラウザ（localStorage）に自動で保存されます。

- 読み込むと「登録情報（○頭分）を読み込みました」と表示され、アドレスバーの `#import=…` は自動で消えます
- すでに保存されている内容には「同じ犬名の犬だけ上書き・他の犬は残す」形でマージします
- URLの `#` より後ろはサーバーへ送られないため、個人情報を入れても公開ページ側には残りません（URL自体は取り扱い注意）
- データの形: `{"v":1,"dogs":[{…}],"owner":{…},"handlerSame":true,"handler":{…},"applicant":{…}}`

## バックアップ・復元（URL・ファイル）

入力画面（ステップ2）のいちばん下「💾 データのバックアップ・復元」から、登録した犬・出陳者・指導手・申込責任者の内容をまるごと控えられます。編集中でまだ保存していない内容も含まれます。入力画面の上の「💾 バックアップ・保存へ ↓」からも同じ欄を開けます。

- 「🔗 バックアップURLを作ってコピー」: 上の専用URL（`#import=…`）を作ってクリップボードへコピー。メモ帳やブックマークに貼っておけば、Safariのデータ消去後でもそのURLを開くだけで元通りになります（コピーできない環境では画面の枠を長押ししてコピー）
- 「💾 ファイルに保存（.json）」: `jkc-entry-backup-YYYYMMDD.json` として保存（iPhoneは「ファイル」アプリ内「ダウンロード」）
- 「📂 ファイルから復元」: 保存したJSONを選ぶと、その端末の登録内容を置きかえます（登録があるときは確認あり。読めないファイルは何も変更しません）
- ファイルの形: `{"v":1,"app":"jkc-entry-app","savedAt":"…","event":"1216","dogs":[…],"currentDogId":"…","owner":{…},"handlerSame":true,"handler":{…},"applicant":{…}}`
- ボタンの下に保存先を小さく表示します（`保存先パス: ファイル ＞ ブラウズ ＞ ダウンロード（iCloud Drive または このiPhone内）`・`ファイル名: jkc-entry-backup-YYYYMMDD.json`・`入力データ保存先: この端末のブラウザ内（localStorage・外部送信なし）`）

## しくみ

- `index.html` 1ファイルで動作します（静的ホスティングでもローカルファイルでも可）
- 大会ごとの申込書PDF（様式ページのみ抽出）をBase64で同梱し、pdf-lib でブラウザ内に記入
- 様式の違いは `scripts/forms_spec.json`（記入位置・丸印/チェック位置・競技クラス・`multiClass`＝1枚に複数クラスを○印できる様式か）で定義
- 日本語は @pdf-lib/fontkit 経由で IPA Pゴシックのサブセット（常用漢字・人名漢字）を埋め込み
- 入力内容は端末の localStorage に保存（サーバーへの送信はありません）
- できあがりの確認用プレビューは pdf.js で描画

## 注意

- 試作版です。提出前に必ず申込書の内容をご確認ください。
- ヘッダーの「※iPhoneのみ」は端末対応の注記です（`index.html` の `id="iosNote"` の1行で変更できます）。
- サンプルデータはすべて架空のものです。
- 同梱フォントは常用漢字・人名漢字までです。それ以外の文字は「?」に置き換わります。
- 1枚の申込書に複数クラスを○印できるのは、阿波北（12/11）・徳島北（12/12）・大阪北ワンズユニティ（12/26）・大阪西ワンズドッグ（12/27）です（アプリでは2クラスまで）。
- 京都トレーナーズ（12/16）は「競技クラスごとに1枚」、東京ブロック（12/19）は「競技クラス1つにつき1枚」、近畿ブロック（12/17）は競技クラスが1度〜3度だけなので、1枚1クラスで作成します。
- フォント: IPA Pゴシック（IPAフォントライセンス v1.0）
